# Tianjing Zhang — personal homepage

An English personal homepage for [tianjingsteve123.github.io](https://tianjingsteve123.github.io/). The warm paper palette, Georgia headings, restrained red accent, numbered sections, and thin rules continue the visual language of the [Kīlauea essay](https://tianjingsteve123.github.io/kilauea/en/).

## Edit and preview

The complete site is in `site/`. Edit `site/index.html` for biography, research, and writing; edit `site/styles.css` for layout. No build step or JavaScript dependency is required.

```sh
python3 -m http.server 8862 --directory site --bind 127.0.0.1
```

Open `http://127.0.0.1:8862/`. Check desktop and mobile before publishing. Commits on `main` deploy the `site/` directory through GitHub Pages.
